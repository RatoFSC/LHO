# LearnHarness for Obsidian（LHO）

![Version](https://img.shields.io/badge/version-v1.1.3-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Obsidian](https://img.shields.io/badge/Obsidian-v1.5.0%2B%20(Desktop%20%2F%20Mobile)-7c3aed)

**LearnHarness for Obsidian（通称：LHO）** は、Obsidianの **「1概念＝1ノート ＋ Wikiリンク ＋ グラフビュー」** と、Google Gemini API による **「理解度診断・ロードマップ生成・ソクラテス式対話学習・忘却曲線復習」** を統合した、AI学習支援プラグインです。

「読んだ・聞いただけで分かったつもりになる（学習の錯覚）」を防ぎ、自分の言葉・思考プロセスを言語化しながら、Obsidian上に生きた知識グラフを育てていくことができます。

- **配布リポジトリ**: https://github.com/RatoFSC/LHO
- **プラグインID**: `obsidian-learn-harness`
- **対応環境**: Obsidian v1.5.0 以上（主に **Obsidian Desktop**［Windows / macOS / Linux］向けに設計。`isDesktopOnly: false` のためモバイル環境でも動作します）

---

## 主な機能

- **理解度診断（Probing）＆ 音声思考入力**
  - 学びたいテーマと目標レベルを入力すると、4〜6問の適応型診断（選択式・短答記述式）で「分かっていること」と「曖昧な境界線」を特定します。
  - マイク録音（`Alt + R` / macOSは `Option + R`）による独り言（Think-Aloud）の疑似リアルタイム文字起こしと、自信度スライダー（0〜100%）を組み合わせた診断に対応しています。
- **ロードマップ ＆ 概念ノートの自動生成**
  - 診断結果をもとに「基礎 → ゴール」の依存関係ツリー（DAG）を自動設計し、各概念ノート（`<概念名>.md`）と全体マップ（`_Roadmap.md`：Mermaid依存関係図＋階層別チェックリスト）を非破壊で生成します。
  - 別テーマの既習ノートとの横断クロスリンク（`## 関連する既習ノート`）や、同一概念ノートの重複作成防止・再利用にも対応しています。
- **ソクラテス式学習・演習（Teach / Practice / 統合演習）＆ ノート追記**
  - **Teachモード**: 予測質問 → ピンポイント解説 → 確認問題の対話で本質理解を作ります。
  - **Practiceモード**: 応用問題と思考プロセスに応じた段階的最小ヒントで「使える知識」へ定着させます。
  - **統合演習**: 2〜4個の学習ノートを組み合わせて複合問題に挑戦し、理解が抜けている前提ノートを特定しながら一括更新できます。
  - **📝 ノートに追記**: AIの解説や採点コメントをボタン1つでノートの末尾へコールアウト形式で追記できます。習得更新時はフロントマター・学習ログ・`_Roadmap.md` も自動同期されます。
- **忘却曲線（SRS）復習 ＆ テスト前「短期集中（追い込み）」モード**
  - 演習時の自信度に応じたSM-2系アルゴリズムで次回復習日を自動計算し、「復習」タブに要復習ノートを一覧表示します（グラフビューの `review_due` と連動）。
  - テスト前には科目別・未習得優先で1問1答を高速演習できる **🔥 短期集中モード**（3段階採点＋苦手ノードだけの再周回機能）を利用できます。
- **学習ダッシュボード（📊 進捗）＆ ストリーク記録**
  - Vault全体の習得率、連続学習日数（ストリーク）、直近7日間の学習実績、科目別の進捗バー、今月のAPI利用概算を一画面で確認できます。
- **講義ノート・配布PDF / 過去問連携**
  - Vault内の Markdownノート（`.md`）や配布スライド・過去問（`.pdf`）を添付して、資料内の定義・記号・章立てに忠実な診断や過去問演習を行えます（初回解析ダイジェストのキャッシュにより、2ターン目以降のPDF重複送信を防いでトークンを節約します）。
- **Google検索グラウンディングによるWeb裏取り**
  - 必要に応じてGoogle検索で正確な定義や最新仕様を裏取りし、参照したWeb出典URLを一覧表示・学習ログへ記録できます（※有料枠のAPIキーが必要です）。
- **SVG図解 ＆ インタラクティブ実験デモ生成**
  - 開いている概念ノートや直近のつまずき内容をもとに **SVG図解** を生成し、ノートへ保存・埋め込み（`![[...svg]]`）できます。
  - スライダーやボタンで動かせる **HTML実験デモ** を安全なサンドボックス内で実行・再生成・保存することも可能です。
- **用途別AIモデル設定・システムプロンプト調整・コスト管理**
  - 6用途（文字起こし・診断・マップ設計・学習演習・Web裏取り・図解デモ）ごとにモデルID・思考レベル・単価を個別設定できるほか、3種類の「かんたんモデルプリセット」と4種類の「科目・スタイル別プロンプトプリセット」を用意しています。
  - サイドバー最下部に今回・今月の概算コスト（円）をリアルタイム表示し、月額コスト警告ラインも設定できます。

## インストール方法（ビルド不要・手動導入）

プログラミング環境やビルド作業は不要です。以下の **3ファイル** をダウンロードして、ご自身のObsidian Vault内へ配置するだけで導入できます。

- `manifest.json`
- `main.js`
- `styles.css`

> [!WARNING]
> **初心者の方へ：ダウンロード時の重要なご注意**
> GitHubのファイル一覧画面でリンクを **「右クリック → 名前を付けて保存」しないでください**。プラグイン本体ではなくWebページのHTMLファイルが保存されてしまい、Obsidianで正常に動作しなくなります。
> 必ず以下の **方法A** または **方法B** のどちらかでダウンロードしてください。

### Step 1：3ファイルをダウンロードする

- **方法A：Releasesページからダウンロードする（おすすめ）**
  1. [Releasesページ](https://github.com/RatoFSC/LHO/releases) を開きます。
  2. 最新バージョンの **Assets** 欄にある `manifest.json`、`main.js`、`styles.css` の3つをそれぞれクリックして保存します。
- **方法B：リポジトリの各ファイル画面からダウンロードする**
  1. [LHOリポジトリ](https://github.com/RatoFSC/LHO) 上で `manifest.json`、`main.js`、`styles.css` をそれぞれクリックして開きます。
  2. ファイル表示画面の右上にある **Download raw file（↓ ボタン）** をクリックして保存します。

### Step 2：Vault内のプラグインフォルダに配置する

お使いのObsidian Vaultフォルダの中にある `.obsidian/plugins/` 配下に **`obsidian-learn-harness`** というフォルダを新規作成し、ダウンロードした3ファイルをそのまま入れてください。

> [!TIP]
> **`.obsidian` フォルダが見当たらない場合（隠しフォルダの表示方法）**
> - **Windows**：エクスプローラー上部の「表示」→「表示」→「**隠しファイル**」にチェックを入れてください。
> - **Mac**：FinderでVaultフォルダを開いた状態で **`Command + Shift + .`（ドット）** を同時に押すと、隠しフォルダが表示されます。

配置後のフォルダ構成は以下のようになります（余計な `.html` 等が混ざっていないか確認してください）：

```text
あなたのObsidian Vault/
└── .obsidian/
    └── plugins/
        └── obsidian-learn-harness/
            ├── manifest.json
            ├── main.js
            └── styles.css
```

### Step 3：Obsidianでプラグインを有効化する

1. Obsidianを一度再起動（または「設定 → コミュニティプラグイン → インストール済みプラグイン」の更新アイコンをクリック）します。
2. 「設定 → コミュニティプラグイン」でコミュニティプラグインを有効にします。
3. インストール済みプラグイン一覧から **「LearnHarness (LHO)」** を探して **ON** にします。

## 初期設定 ＆ 使い方（最初の3ステップ）

### Step 1：Gemini APIキーを取得して設定する
1. [Google AI Studio](https://aistudio.google.com/) にアクセスし、ご自身のGoogleアカウントで **Gemini APIキー** を発行します。
2. Obsidianの「設定 → LearnHarness (LHO)」を開き、**「Gemini APIキー」** 欄に取得したキーを貼り付けます。

### Step 2：「かんたんモデルプリセット」を選ぶ
設定画面の **「用途別AIモデル・単価設定」** にある「かんたんモデルプリセット」から、使い方に合う構成をワンクリックで選べます。

- **まずは無料で試したい場合**：**「節約（無料枠対応）」** を選択してください。
  - ※「節約」プリセットでは主要用途に無料枠対応モデルが設定されます。なお、**Google検索によるWeb裏取りリサーチ機能のみ有料枠（課金有効化済みAPIキー）が必要** ですので、無料枠で使う場合は「Web裏取りリサーチ（Google検索）」をOFFのままご利用ください。
- **精度とコストのバランス重視（初期設定）**：**「バランス（推奨）」**
- **専門科目・試験直前の徹底演習**：**「高精度（専門科目・テスト前）」**

### Step 3：接続テストをして画面を開く
1. 設定画面のAPIキー入力欄のすぐ下にある **「接続テスト」** ボタンを押し、緑色の成功メッセージが表示されることを確認します。
2. 画面左端のリボンアイコン（🎓）をクリックするか、コマンドパレット（Windows: `Ctrl + P` / Mac: `Cmd + P`）から **`LearnHarness: Open LearnHarness`** を実行すると、右サイドバーにLearnHarness画面が開きます。
   - ※開いたタブは、Obsidianの通常パネルと同様にドラッグしてメインエディタ領域へ移動して使うこともできます。
3. 「診断・マップ生成」タブで学びたいテーマを入力し、理解度診断からスタートしてください！

> [!IMPORTANT]
> **API利用料に関するご注意**
> - 本プラグインで使用するGemini APIキーおよび発生するAPI利用料金は、**利用者ご自身の負担** となります。
> - 設定画面の **「月額コスト警告ライン（円）」**（デフォルト `500` 円、`0` で警告無効）を設定しておくと、80%／100%超過時にサイドバー下部へ注意・警告が表示されます。単価はGoogle AI Studioの最新料金表に合わせて各自調整してください。

## おすすめ設定：グラフビューの色分け

LearnHarnessが生成する概念ノートにはフロントマターに `lh_node: true` が付与されます。
Obsidianのグラフビュー右上の **「⚙ グラフ設定 → グループ → 新規グループ」** に、以下の4つのAND検索クエリを **上から順番に** 登録すると、普段使っている既存ノートと混ざることなく、復習期限や習得状況が一目で色分けされます。

| 優先順 | 状態 | 検索クエリ（コピー用） | 推奨色 |
| :---: | :--- | :--- | :---: |
| 1 | 復習期限到来（最優先） | `["lh_node":true] ["review_due":true]` | 赤 |
| 2 | 習得済み | `["lh_node":true] ["status":mastered]` | 緑 |
| 3 | 学習中 | `["lh_node":true] ["status":learning]` | 青 |
| 4 | 未学習 | `["lh_node":true] ["status":unstarted]` | グレー |

> [!TIP]
> プラグイン設定画面の一番下にある **「グラフビュー色分け設定（本番Vault向け）」** を開くと、上記4つのクエリを **ワンクリックでコピー** できます。また、グラフビューの「フィルタ → 添付ファイル」をONにすると、参照資料（`.pdf`）とのつながりも可視化されます。
